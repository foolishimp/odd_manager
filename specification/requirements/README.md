# Project Requirements

Project-specific requirement families live in this folder.

Resolve the exact method basis through `../../stdo_odd_manager.json`, then use
`../GOVERNANCE.md` and `../REFERENCE_FRAME_BASIS.md` as the project application
and shared evaluation-frame routes when writing or revising these files.

## Rules

- Write requirement families as separate `*.md` files.
- Use deterministic REQ headers in the form `### REQ-...`.
- Give each family an explicit `Category` using the spec-method classes.
- Keep the live requirement surface forward-looking and free of inherited
  product-line vocabulary that is no longer canonical.
